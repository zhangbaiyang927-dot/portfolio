从0到1：一场针对"价格敏感型新手"的IMC精准战役

整合营销 新品上市 全链路闭环 B端渠道激活
01 / 为什么做这件事？
「这个市场不缺好产品，缺的是让用户敢尝试的理由。」

俄罗斯烟草替代品市场正处于高速增长但心智混乱的阶段。主流品牌集中在"高端性能"赛道，用复杂参数和高端定价争夺存量玩家，却忽视了最大的增量群体：
价格敏感型新手用户——他们想尝试新型烟草产品，但被两个门槛挡住：

🧠 认知门槛

  • 看不懂参数
  • 分不清品类
  • 不知道"什么适合我"

💰 价格门槛

  • 不愿为"不确定是否喜欢"的产品支付高价
结论：我们品牌资产集中在"技术创新"，但在大众认知中缺乏"亲和力"。这款产品的使命不是做一款低价产品，而是成为品牌与新用户之间的"第一触点"。
先用低价消除决策风险 → 再用产品力建立信任 → 最后用Bot体系沉淀长期价值
02 / 策略框架
「用一次低成本的尝试，换一个长期的用户。」
表层价格驱动首发价 + 赠品，降低首次尝试的心理门槛
中层体验驱动门店路演 + 品鉴会，让"看"变成"试"
深层关系驱动Bot积分体系，把"一次购买"变成"持续连接"
为什么是这个顺序？
价格是 hook没有低价，目标用户根本不会注意到你
体验是转化器只有摸到、试到，用户才会相信"低价≠低质"
关系是护城河竞品可以复制价格，但复制不了已沉淀的用户习惯
03 / 线上矩阵
不是"发内容"，是"设计旅程"

💬 Telegram / 品牌 Bot

做了什么：

首发专属优惠券 + 抽奖机制 + 小票上传引导

为什么这样做：
  • 优惠券解决的是"用户为什么现在买"
  • 抽奖解决的是"用户为什么愿意分享"
  • 小票上传解决的是"如何把线下购买者变成线上可触达用户"
关键细节：优惠券设置7天有效期，制造轻微紧迫感，避免"先收藏再说"

📱 社交媒体（TG / YOUTUBE）

做了什么：

统一话题标签 #XLIMGOLITE + KOL开箱 + KOC晒单

为什么这样做：
  • KOL负责"种草"——展示产品在真实场景中的使用，解决"这个东西到底怎么样"
  • KOC负责"背书"——普通用户的真实反馈比KOL更有说服力，解决"是不是广告"
  • 统一标签——让所有内容可被聚合、可被追踪，也为后续用户自发内容预留入口
04 / 线下联动：B2B2C的精准渗透
「不是让B端帮品牌卖货，而是帮B端更好地服务他们的客户。」

MAVERICK & OXVA Tasting Event 的启发

MAVERICK 有门店资源但缺品牌认知，OXVA 有成熟产品但缺区域渗透——这是一场优势互换。

为什么选新西伯利亚？

  • 不是一线城市（莫斯科/圣彼得堡），市场竞争没那么激烈
  • 区域市场用户对"新品牌"接受度高，品牌有机会先入为主
  • MAVERICK 在当地有扎实的门店网络
关键决策
01

只面向B端

品鉴会只面向销售人员、门店经营者、经销商，不直接面向C端。
为什么？ B端是杠杆。影响1个门店主 = 影响他背后几百个日常进店用户。

02

五城巡回

五城巡回，每城只办一场。
为什么？ 制造稀缺性，让被邀请的人觉得"被重视"，形成口碑传播。

03

现场不销售

现场只体验，不直接销售。
为什么？ 这是品鉴会，不是促销会。目标是建立合作关系，不是冲销量。
